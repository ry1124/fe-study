## 第11章 ストラテジ（企業活動・法務・システム戦略）

会社の経営の考え方、お金の計算、法律、システムを導入するときの考え方を学びます。

> **この章のゴール**
> ・経営やマーケティングの分析方法の名前と中身を結び付けられる
> ・損益分岐点と、利益の計算ができる
> ・著作権・特許権・派遣などの法律の基本が分かる
> 科目Aで12問前後。用語の問題が多いので、短い時間で点を取れます。

### ① 経営戦略の分析方法

#### SWOT分析
会社の状況を、4つの面から整理します。
| | よい面 | 悪い面 |
| --- | --- | --- |
| 会社の中（内部） | **S**trength（強み） | **W**eakness（弱み） |
| 会社の外（外部） | **O**pportunity（機会） | **T**hreat（脅威） |

例：強み＝技術力が高い、弱み＝知名度が低い、機会＝健康ブームが来ている、脅威＝強い競合が参入してきた

#### PPM
会社の事業を、「市場の伸び（成長率）」と「自社のシェア（占有率）」で4つに分けます。
| | シェアが高い | シェアが低い |
| --- | --- | --- |
| 市場の伸びが大きい | **花形**：人気だがお金もかかる | **問題児**：伸びるかもしれない |
| 市場の伸びが小さい | **金のなる木**：お金をたくさん生む | **負け犬**：撤退も考える |

> **覚え方**：「金のなる木」で稼いだお金を、「問題児」や「花形」に投資する。

#### その他の分析方法
| 名前 | 内容 |
| --- | --- |
| 3C分析 | 顧客（Customer）・競合（Competitor）・自社（Company）の3つの視点 |
| 4P | 売る側から見たマーケティングの4要素：製品・価格・流通・販売促進 |
| バランススコアカード | 4つの視点（財務・顧客・業務プロセス・学習と成長）で目標を立てる |
| コアコンピタンス | 他社がまねできない、自社の中心となる強み |
| ブルーオーシャン | 競争相手がいない、新しい市場 |
| ロングテール | ネット販売で、少しずつしか売れない商品の合計が大きくなること |

| --- | --- | --- |

### ② 会計（お金の計算）

#### 損益分岐点
「売上と費用がちょうど同じになり、利益が0になる売上高」です。これより売れれば黒字、少なければ赤字です。
- **固定費**：売上に関係なくかかる費用（家賃、人件費）
- **変動費**：売れた分だけかかる費用（材料費）
- **変動費率**：売上のうち変動費が占める割合（変動費 ÷ 売上高）

**損益分岐点売上高 ＝ 固定費 ÷ (1 − 変動費率)**

#### 例題
固定費 300万円、変動費率 0.4
① 売上のうち、固定費と利益に回せる割合：1 − 0.4 ＝ 0.6
② 300 ÷ 0.6 ＝ **500万円**

#### 目標の利益を出すための売上
**(固定費 ＋ 目標の利益) ÷ (1 − 変動費率)**
例：上の条件で利益を 60万円出したい → (300 ＋ 60) ÷ 0.6 ＝ 600万円

#### 利益の段階
| 名前 | 計算 | 意味 |
| --- | --- | --- |
| 売上総利益 | 売上高 − 売上原価 | 商品そのものの儲け |
| 営業利益 | 売上総利益 − 販売費及び一般管理費 | 本業の儲け |
| 経常利益 | 営業利益 ＋ 営業外収益 − 営業外費用 | 利息なども含めたいつもの儲け |
| 当期純利益 | 税金なども引いた最終的な儲け | |

#### 会社の健康診断（財務指標）
- **ROE** ＝ 当期純利益 ÷ 自己資本（株主のお金でどれだけ儲けたか）
- **流動比率** ＝ 流動資産 ÷ 流動負債（すぐ払う力。100%を超えていれば安心）

#### 在庫の評価
- **先入先出法**：先に仕入れたものから先に出したと考える
- **移動平均法**：仕入れるたびに平均の値段を計算し直す

#### 減価償却
高い物（パソコンなど）を買ったとき、その代金を、使う年数に分けて少しずつ費用にすることです。
定額法：(買った値段 − 残りの価値) ÷ 使う年数。例：100万円で5年なら、毎年20万円。

### ③ 法律

#### 知的財産権
| 権利 | 守るもの | 手続き |
| --- | --- | --- |
| 著作権 | 作品（文章、音楽、**プログラム**） | **作った時点で自動的に**生まれる |
| 特許権 | 発明 | 特許庁に出願・登録が必要 |
| 意匠権 | デザイン | 出願・登録が必要 |
| 商標権 | 商品のマークや名前 | 出願・登録が必要 |

> **間違えやすい所**：プログラムは著作権で守られるが、**アルゴリズム（考え方）やプログラム言語は守られない**。

- **職務著作**：会社の仕事として作ったものの著作権は、原則として**会社**のもの
- **請負で作ったもの**：契約で決めていなければ、**作った側**（受注した会社）のもの

#### 働き方の契約
| 契約 | 仕事の指示をするのは | 特徴 |
| --- | --- | --- |
| 労働者派遣 | **派遣先**（実際に働く会社） | 雇っているのは派遣元 |
| 請負 | **受注した会社**（請負元） | 仕事を完成させる責任がある |
| 準委任 | 受注した会社 | 完成ではなく、作業をきちんと行う責任 |

> **偽装請負**：請負なのに、発注した会社が直接、作業する人に指示すること。法律違反です。

#### その他の法律
- **不正アクセス禁止法**：他人の ID・パスワードを勝手に使うこと、**他人に教えること**も禁止
- **個人情報保護法**：個人情報を本人の同意なく他人に渡してはいけない（命を守るためなど例外あり）。病歴などは「要配慮個人情報」として特に慎重に扱う
- **不正競争防止法**：会社の秘密（営業秘密）を盗むことなどを禁止
- **PL法**（製造物責任法）：製品の欠陥でけがをしたら、作った会社が責任を負う。ソフトウェア単体は対象外
- **取適法**（旧 下請法。2026年1月に改正・名前が変更）：発注する側が、受注した中小企業への代金を不当に減らしたり、支払いを遅らせたりすることを禁止。試験では「下請法」の名前で出ることもあります

### ④ 経営・業務の用語

| 用語 | 意味 |
| --- | --- |
| CRM | お客さんとの関係を大切にし、情報を管理する |
| SCM | 材料の調達から販売まで、会社をまたいで全体を最適化する |
| ERP | 会社全体の経営資源（人・物・お金・情報）をまとめて管理する |
| BPR | 仕事の進め方を、根本から作り直す |
| RPA | 人がパソコンで行う決まった作業を、ソフトのロボットが代わりに行う |
| BCP | 災害などが起きても、大事な仕事を続ける・早く戻すための計画 |
| CIO | 情報システムの最高責任者 |

### ⑤ システムを導入するとき（調達）

1. **RFI**（情報提供依頼書）：どんな製品や技術があるか、いろいろな会社に聞く
2. **RFP**（提案依頼書）：作ってほしいシステムの条件を示し、提案を出してもらう
3. 提案を比べて、会社を選ぶ
4. 契約する

> **覚え方**：I は Information（情報をください）、P は Proposal（提案をください）。

### この章のまとめ

- SWOT は内部（強み・弱み）と外部（機会・脅威）
- PPM の「金のなる木」は、シェアが高く市場の伸びが小さい
- 損益分岐点 ＝ 固定費 ÷ (1 − 変動費率)
- 著作権は自動で生まれる。アルゴリズムは守られない
- 派遣は派遣先が指示、請負は請負元が指示
- RFI は情報集め、RFP は提案の依頼
