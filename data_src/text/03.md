## 第3章 擬似言語の読み方とトレース（科目B）

科目Bのプログラム問題は、IPAが決めた「擬似言語」という書き方で出ます。その読み方と、プログラムを手で追いかける方法（トレース）を学びます。

> **この章のゴール**
> ・擬似言語のプログラムを、1行ずつ意味を言いながら読める
> ・変数の値の変化を、表に書いて追いかけられる（トレース）
> ・空欄に入る答えを、具体的な数を当てはめて確かめられる
> 科目Bの20問のうち16問がプログラムの問題です。**合格のカギはこの章**です。

### ① プログラムってなに？

#### イメージ
プログラムは、コンピュータへの「作業の指示書」です。料理のレシピのように、上から順番に1行ずつ実行されます。

#### 変数
**変数**は、値を入れておく「名前付きの箱」です。
```
整数型: x ← 5
```
これは「x という名前の、整数を入れる箱を用意して、5 を入れる」という意味です。
- 「←」は「右の値を、左の箱に入れる」（代入）
- 「整数型」は箱の種類（整数を入れる）。ほかに「実数型」「文字列型」「論理型（true か false）」などがあります

```
x ← x ＋ 1
```
これは「x の今の値に 1 を足して、x に入れ直す」。つまり **x を1増やす** という意味です（数学の等式ではありません）。

### ② 擬似言語の書き方一覧

| 書き方 | 意味 |
| --- | --- |
| ○整数型: f(整数型: n) | f という関数を作る。n を受け取り、整数を返す |
| ○proc(整数型: n) | 値を返さない手続 |
| return x | 関数を終えて、x を呼び出し元に返す |
| 整数型の配列: a ← {3, 1, 2} | 配列（番号付きの箱の並び）を作る |
| a[2] | 配列 a の2番目（**番号は1から**始まる）。この例では 1 |
| aの要素数 | 配列の長さ。この例では 3 |
| 大域: 整数型: cnt | どの関数からも使える変数 |
| /* 〜 */ | 注釈（説明のメモ）。実行されない |

#### 条件分岐（if）
```
if (x ＞ 10)
  "大" を出力する
elseif (x ＞ 5)
  "中" を出力する
else
  "小" を出力する
endif
```
上から順に条件を調べ、**最初に当てはまったところだけ**を実行します。x ＝ 12 なら「大」だけ出力し、elseif は調べません。

#### 繰り返し（for）
```
for (i を 1 から 5 まで 1 ずつ増やす)
  i を出力する
endfor
```
i を 1、2、3、4、5 と変えながら、間の行を5回実行します。

#### 繰り返し（while）
```
while (x ＜ 100)
  x ← x × 2
endwhile
```
条件が真（正しい）の間、繰り返します。条件は**繰り返しの前に**調べるので、最初から偽なら1回も実行しません。

#### 繰り返し（do 〜 while）
```
do
  x ← x × 2
while (x ＜ 100)
```
先に1回実行してから、条件を調べます。**必ず1回は実行**されます。

#### 演算子と優先順位
| 先に計算 | 演算子 |
| --- | --- |
| 1 | not、単項の ＋ − |
| 2 | ×、÷、mod |
| 3 | ＋、− |
| 4 | ＝、≠、＜、≦、＞、≧ |
| 5 | and |
| 6 | or |

- **mod** は割った余り。7 mod 3 ＝ 1。「x mod 2 ＝ 0」なら x は偶数
- **÷** は問題文で「商の小数点以下を切り捨てる」などと決められていることが多い。必ず問題文を確認する
- **and** は両方が真のとき真、**or** はどちらかが真なら真。and の方が先に計算される

> **間違えやすい所**：「x ＞ 10 or y ＞ 10 and x ＞ y」は、and が先なので「x ＞ 10」または「(y ＞ 10 and x ＞ y)」と読みます。

### ③ トレース（手で追いかける）のやり方

プログラムを頭の中だけで追うと、必ずどこかで間違えます。**メモ用紙に表を書く**のがいちばん確実です。

#### 手順
1. 変数の名前を横に並べた表を書く
2. 1行実行するたびに、**変わった変数だけ**新しい値を書く
3. 繰り返しは、何周目かを左に書く
4. 配列は、変わったら1行に全部書き直す

#### 例題1：for と if のトレース
```
○整数型: f(整数型: n)
  整数型: s ← 0
  整数型: i
  for (i を 1 から n まで 1 ずつ増やす)
    if (i mod 2 ＝ 0)
      s ← s ＋ i
    else
      s ← s − 1
    endif
  endfor
  return s
```
f(4) の戻り値を求めます。
| i | i mod 2 | どちらを実行 | s |
| --- | --- | --- | --- |
| 開始 | | | 0 |
| 1 | 1 | else（s − 1） | −1 |
| 2 | 0 | if（s ＋ i） | 1 |
| 3 | 1 | else | 0 |
| 4 | 0 | if | 4 |
答え：**4**

#### 例題2：while のトレース
```
整数型: x ← 84
整数型: y ← 36
整数型: r
while (y ≠ 0)
  r ← x mod y
  x ← y
  y ← r
endwhile
x を出力する
```
| 周 | r | x | y |
| --- | --- | --- | --- |
| 開始 | | 84 | 36 |
| 1 | 84 mod 36 ＝ 12 | 36 | 12 |
| 2 | 36 mod 12 ＝ 0 | 12 | 0 |
y ＝ 0 になったので終わり。出力は **12**（84 と 36 の最大公約数。これを「ユークリッドの互除法」という）

#### 例題3：配列のトレース（隣と比べて入れ替える）
```
整数型の配列: a ← {5, 3, 4}
整数型: j, tmp
for (j を 1 から 2 まで 1 ずつ増やす)
  if (a[j] ＞ a[j ＋ 1])
    tmp ← a[j]
    a[j] ← a[j ＋ 1]
    a[j ＋ 1] ← tmp
  endif
endfor
```
| j | 比べる | 入れ替える？ | a |
| --- | --- | --- | --- |
| 開始 | | | {5, 3, 4} |
| 1 | a[1]＝5 と a[2]＝3 | する | {3, 5, 4} |
| 2 | a[2]＝5 と a[3]＝4 | する | {3, 4, 5} |

> **入れ替えの決まり文句**：tmp ← a[j]、a[j] ← a[j＋1]、a[j＋1] ← tmp の3行で、2つの値を入れ替えます。tmp（一時置き場）がないと、片方の値が消えてしまいます。

### ④ 空欄を埋める問題の解き方

科目Bでは、プログラムの一部が空欄になっていて、そこに入るものを選ぶ問題がよく出ます。

#### 手順
1. **問題文を先に読み**、そのプログラムが「何をするものか」をつかむ
2. 空欄の前後の行を読み、空欄で「何をしたいのか」を考える
3. **小さい具体例**（要素が3〜4個の配列など）を自分で決める
4. 選択肢を1つずつ空欄に入れて、具体例でトレースし、正しい結果になるか確かめる

#### 境目のチェック
「1 から n まで」か「1 から n − 1 まで」か、「＜」か「≦」か、のような違いは、**最初の1周と最後の1周だけ**確かめれば判断できます。

#### 例題：配列を逆順にする
```
for (i を 1 から 〔 ア 〕 まで 1 ずつ増やす)
  a[i] と a[〔 イ 〕] を入れ替える
endfor
```
具体例 {1, 2, 3, 4}（n＝4）で考えます。
- 1番目と4番目、2番目と3番目を入れ替えればよい
- i ＝ 1 の相手は 4 番目、i ＝ 2 の相手は 3 番目 → 相手は **n − i ＋ 1**
- 2回で終わりにする（最後までやると、もう一度入れ替えて元に戻る）→ ア は **n ÷ 2**

### ⑤ よく出るパターン

| パターン | プログラムの形 |
| --- | --- |
| 合計 | s ← 0 から始め、s ← s ＋ a[i] を繰り返す |
| 個数を数える | 条件に合うときだけ cnt ← cnt ＋ 1 |
| 最大値 | max ← a[1] から始め、a[i] ＞ max なら max ← a[i] |
| 入れ替え | tmp を使った3行 |
| 逆順 | i 番目と n − i ＋ 1 番目を入れ替える |
| 偶数・倍数 | x mod 2 ＝ 0、x mod 3 ＝ 0 |
| 2進数にする | 2で割った余り（x mod 2）を集め、x ← x ÷ 2 |
| 探索・並べ替え | 第2章の方法をプログラムにしたもの |

### ⑥ 関数と再帰の読み方

#### 関数の呼び出し
関数を呼ぶと、その関数を最後まで実行してから、呼んだ場所に戻って続きを実行します。
```
○proc1()
  "A" を出力する
○proc2()
  proc1()
  "B" を出力する
```
proc2() を呼ぶと：proc1 で "A" を出力 → 戻って "B" を出力。結果は A、B。

#### 再帰（自分自身を呼ぶ）
```
○整数型: f(整数型: n)
  if (n ≦ 1)
    return 1
  endif
  return n × f(n − 1)
```
f(3) をたどると：
- f(3) ＝ 3 × f(2)
- f(2) ＝ 2 × f(1)
- f(1) ＝ 1（ここで止まる）
- 戻りながら計算：f(2) ＝ 2 × 1 ＝ 2、f(3) ＝ 3 × 2 ＝ 6

> **コツ**：再帰は、呼び出しごとに字下げしてメモに書くと、迷子になりません。

### ⑦ リスト（オブジェクト）の書き方

連結リストは、次のような形で出ます。
```
ListElement: val（値）, next（次の要素への参照）
prev ← listHead
while (prev.next が 未定義 でない)
  prev ← prev.next
endwhile
```
- 「**.**」は「その要素の中の項目」。prev.next は「prev の次の要素」
- 「**未定義**」は「何も指していない」。最後の要素の next は未定義
- この例は「next が未定義になるまで進む」＝ **最後の要素まで進む** という意味

### この章のまとめ

- 「←」は代入。x ← x ＋ 1 は「x を1増やす」
- 配列の番号は1から。aの要素数 は長さ
- if は最初に当てはまった所だけ。while は前に判定、do〜while は必ず1回実行
- mod は余り。and は or より先に計算
- トレースは必ず表に書く。変わった変数だけ書き足す
- 空欄問題は、小さい具体例を作って選択肢を当てはめる。境目は最初と最後の1周で確かめる
